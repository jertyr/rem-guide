Trade Finishes

Trade finishes are the final installations for HVAC, plumbing, and electrical after painting is complete. Each trade needs final fixtures on site and an inspection scheduled. Coordinate deliveries and selections ahead of time so trades aren't waiting on materials.

Quick Reference

  • All painting must be complete before trades start finishes
  • Get final fixtures on site before the trade arrives
  • Confirm device style (standard or decora) and color (white, almond, etc.) before electrical finish
  • Mark dimmer locations before electrical finish
  • Each trade needs a final inspection

Process

  • HVAC
    • Install registers, grilles, and diffusers
    • Install thermostats
    • Start up and test system (heating and cooling cycles)
    • Schedule and pass final HVAC inspection
  • Plumbing
    • Get final fixtures on site (faucets, sinks, toilets, shower trim, accessories)
    • Install faucets and sinks
    • Set toilets
    • Install shower trim (valve trim, showerheads, handles)
    • Connect dishwasher, ice maker, disposal
    • Install exterior hose bibs if not done at rough
    • Check all connections for leaks. Run every fixture
    • Schedule and pass final plumbing inspection
  • Electrical
    • Get final fixtures on site (light fixtures, bath fans, appliance connections)
    • Confirm switch/outlet style: standard or decora
    • Confirm device color: white, almond, etc.
    • Mark dimmer locations on the plans or on the wall
    • Install switches, outlets, and cover plates
    • Install dimmers at marked locations
    • Install light fixtures
    • Install bath exhaust fans
    • Install smoke detectors and CO detectors
    • Wire and connect appliances (range, dishwasher, disposal, microwave)
    • Label breaker panel
    • Test all circuits, GFCIs, and AFCIs
    • Schedule and pass final electrical inspection

Best Practices

  • Protect finished floors and paint during trade finishes. Trades are focused on their work, not your finishes
  • Walk the job with each trade before they start to review fixture locations and any changes from the rough
  • Keep spare devices (switches, outlets, cover plates) on site in the correct color and style for punch list
  • Schedule inspections in advance. Final inspections often need to be booked days or weeks out depending on jurisdiction

Client Communication

  • All fixture selections and finishes (faucet style, light fixtures, device color) need to be finalized and on site before this phase. Late changes delay trades and may require reordering
  • Final inspections must pass before the certificate of occupancy is issued. If an inspection fails, the trade returns to correct the issue and reschedule
