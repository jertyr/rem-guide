Maintenance

How to update

Target: first week of each month. Each row's exact URL and field name are in the "Fetch from" column above and in the HTML comments at the top of this file.

  1. Shift columns left — move current values into the prior-month columns; drop the oldest column's data.
  2. Update column headers — rename both <thead> rows to the new month (e.g. "May '26" → "Jun '26", shift the rest).
  3. Enter new readings — fetch each value from the source listed in the "Fetch from" column. Update the item-spec text to reflect the new data period.
  4. Update trend arrows — compare new current to the prior column. Use ↑ / ↓ / → and the CSS class up / down / flat.
  5. Update the header date — change "Updated May 30, 2026" to the new date.

Monthly indicators

  • 30-yr mortgage rate weekly → use month-end
    freddiemac.com/pmms · FRED: MORTGAGE30US
  • Fed funds rate FOMC meetings only
    FRED: DFEDTARU (upper bound)
  • Housing starts / permits / completions monthly, 3-wk lag
    census.gov/construction/nrc · Table 1 SAAR totals
  • Case-Shiller 20-City HPI monthly, 2-month lag
    FRED: SPCS20RSA · index level + YoY %
  • Consumer Confidence monthly, last Tuesday
    conference-board.org · headline CCI

  • Credit card utilization quarterly, ~6-wk lag
