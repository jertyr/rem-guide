Footings Checklist

Materials / tools needed

  • ☐ Shovels
  • ☐ Post hole diggers
  • ☐ Rakes
  • ☐ Compactors
  • ☐ Lumber, forms, or sonotubes
  • ☐ Stakes
  • ☐ String
  • ☐ Levels or lasers
  • ☐ Tape measure
  • ☐ Rebar or wire mesh
  • ☐ Tie wire
  • ☐ Bolt cutters, rebar cutters, or angle grinder

Process

  • ☐ Call MISS DIG / utility locator (or confirm it’s already complete)
  • ☐ Establish elevation
  • ☐ Establish outside dimension of footing (string lines / lasers / stakes)
  • ☐ Confirm footing location relative to foundation wall (foundation centered on footing)
  • ☐ Install drains or weeps (and set sump crock if needed)
  • ☐ Install reinforcement (rebar) per plan
  • ☐ Schedule and pass footing inspection (forms, reinforcement, drains in place)
  • ☐ Pour concrete after passing inspection
  • ☐ Trowel top of footing flat and level (or as specified)
  • ☐ Remove formwork when possible after pour (do not bury wood forms)
